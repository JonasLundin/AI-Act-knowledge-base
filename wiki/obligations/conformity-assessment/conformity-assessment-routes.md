# Summary

**Article 43** of Regulation (EU) 2024/1689 specifies the mandatory **conformity assessment procedures** that providers must carry out prior to placing a high-risk AI system on the market[^regulation-eu-2024-1689].

# Conformity Assessment Pathways

```
+-------------------------------------------------------------------+
|               ARTICLE 43 CONFORMITY ASSESSMENT ROUTES             |
+-------------------------------------------------------------------+
| ROUTE 1: INTERNAL CONTROL (Annex VI)                              |
| - Standard route for standalone Annex III systems                 |
| - Applies when harmonised standards exist and are applied in full |
| - Self-assessment by provider without notified body mandatory audit|
+-------------------------------------------------------------------+
| ROUTE 2: NOTIFIED BODY ASSESSMENT (Annex VII)                     |
| - Mandatory for Biometrics (Annex III Point 1) unless harmonised  |
|   standards are fully adhered to                                  |
| - Mandatory when harmonised standards do not exist or are departed|
|   from by provider                                                |
| - Assessment of QMS (Annex VII Point 3) and Technical Dossier     |
|   (Annex VII Point 4) by accredited Notified Body                 |
+-------------------------------------------------------------------+
| ROUTE 3: ANNEX I EMBEDDED SAFETY COMPONENTS                       |
| - Follows conformity assessment procedure of the underlying product|
|   legislation (e.g. MDR, Machinery Regulation, Civil Aviation)    |
+-------------------------------------------------------------------+
```
