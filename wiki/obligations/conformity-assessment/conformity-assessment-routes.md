# Summary

**Article 43** of Regulation (EU) 2024/1689 specifies the mandatory **conformity assessment procedures** that providers must carry out prior to placing a high-risk AI system on the market or putting it into service[^regulation-eu-2024-1689].

# Conformity Assessment Pathways

```
+-------------------------------------------------------------------+
|               ARTICLE 43 CONFORMITY ASSESSMENT ROUTES             |
+-------------------------------------------------------------------+
| ROUTE 1: INTERNAL CONTROL (Annex VI)                              |
| - Standard route for Annex III standalone systems points 2 to 8   |
|   (critical infrastructure, education, employment, public services,|
|   law enforcement, migration, justice) REGARDLESS of whether     |
|   harmonised standards exist.                                     |
| - Also applies to Point 1 (biometrics) ONLY IF harmonised         |
|   standards exist and are applied in full.                        |
| - Self-assessment by provider without notified body involvement.  |
+-------------------------------------------------------------------+
| ROUTE 2: NOTIFIED BODY ASSESSMENT (Annex VII)                     |
| - Mandatory for Biometrics (Annex III Point 1) where harmonised   |
|   standards do not exist, or the provider has not applied them,   |
|   or common specifications are not available (Article 43(1)).     |
| - Comprehensive audit of QMS (Annex VII Point 3) and Technical    |
|   Documentation Dossier (Annex VII Point 4) by a Notified Body.   |
+-------------------------------------------------------------------+
| ROUTE 3: ANNEX I EMBEDDED SAFETY COMPONENTS (Article 43(3))       |
| - Follows the conformity assessment procedure of the underlying   |
|   Union product harmonisation legislation listed in Annex I       |
|   (e.g. MDR, Machinery Regulation, Civil Aviation).               |
+-------------------------------------------------------------------+
```
